 Cyclistic Bike-Share Data Analysis

 Project Overview
This project explores how annual members and casual riders use Cyclistic's bike-sharing services differently. The analysis aims to identify usage patterns and generate insights that can support data-driven business decisions.

 Business Question
How do annual members and casual riders use Cyclistic bikes differently?

 Tools and Technologies
- SQL Server Management Studio (SSMS)
- SQL
- Tableau Public
- Microsoft Excel (where applicable)

 Data Preparation
The project involved preparing and combining bike-share trip records into a cleaned dataset for analysis.

The resulting analysis table was named `clean_combined_trips`.

 Analysis Areas
- Monthly ride patterns
- Daily ride patterns
- Hourly ride patterns
- Ride duration comparisons
- Differences between annual members and casual riders

 Key Findings

1. Ride Volume: Annual members accounted for 64% of total rides (3.49 million), while casual riders accounted for 36% (1.97 million).

2. Ride Duration: Casual riders recorded longer average ride durations (approximately 20–26 minutes) compared with annual members (approximately 11–14 minutes).

3. Bike Preference:Both rider categories demonstrated substantial use of electric bikes.

 Business Recommendations

- Develop targeted membership campaigns for casual riders.
- Explore incentives that encourage frequent casual riders to become annual members.
- Use rider behaviour patterns to improve service planning and bike availability.
