# Cyclistic Bike-Share Data Analysis

## Project Overview
This project explores how annual members and casual riders use Cyclistic's bike-sharing services differently. The analysis aims to identify usage patterns and generate insights that can support data-driven business decisions.

## Business Question
How do annual members and casual riders use Cyclistic bikes differently?

## Tools and Technologies
- SQL Server Management Studio (SSMS)
- SQL
- Tableau Public
- Microsoft Excel (where applicable)

## Data Preparation
The project involved preparing and combining bike-share trip records into a cleaned dataset for analysis.

The resulting analysis table was named `clean_combined_trips`.

## Analysis Areas
- Monthly ride patterns
- Daily ride patterns
- Hourly ride patterns
- Ride duration comparisons
- Differences between annual members and casual riders
